# 지게차운전기능사 실기 시뮬레이터 (v0.3)

브라우저에서 바로 실행하는 3D 지게차 실기(작업형) 연습 시뮬레이터입니다.

## 실행
1. `index.html`을 Chrome 또는 Edge에서 엽니다. 설치는 필요 없습니다.
2. 인터넷 연결이 필요합니다. Three.js를 jsDelivr CDN에서 불러옵니다.
3. 시작 화면에서 모드(시험/연습)와 보조 옵션을 고른 뒤 **시험 시작**을 누릅니다.

## 시험 흐름 (제한시간 4분)
1. 출발 전 준비: 안전벨트를 매고(B), 포크를 지면에서 20~30cm 올린 뒤(R), 주차 브레이크를 풉니다(N). 포크를 올리기 전이나 주차 브레이크가 걸려 있으면 차가 움직이지 않습니다.
2. 출발선을 통과합니다. **4분 계시는 이때부터 시작됩니다.**
3. **A** 드럼 위 팔레트에 포크를 끝까지 넣고 들어 올립니다.
4. 후진으로 빠진 뒤 포크를 20~30cm로 내리고 마스트를 뒤로 기울인 채 전진 코스를 주행합니다.
5. **B** 드럼 위에 팔레트를 내려놓습니다. 포크를 조금 더 내려 팔레트 밑판에서 떼야 하역으로 인정됩니다.
6. 포크를 뺀 채 **후진선**(B 하역선에서 3.5m 뒤)까지 후진해 정지하고, 포크를 지면에 완전히 내립니다. 후진선에서는 포크가 지면에 닿아도 됩니다.
7. 포크를 다시 올리고 전진해 B에서 팔레트를 다시 들어 올립니다. 후진선 절차를 건너뛰면 감점됩니다.
8. 후진으로 코스를 빠져나와 **A** 드럼 위 원래 자리에 내려놓습니다.
9. 후진해 출발선(정지선) 안쪽에 정지한 뒤 포크를 지면까지 내리면 종료됩니다.

100점 만점에 60점 이상이고 실격이 없으면 합격입니다.

## 조작
| 키 | 동작 |
|---|---|
| W / S | 전진·후진 가속 (반대 방향 키는 감속) |
| A / D | 조향 (뒷바퀴 조향, 실제 지게차처럼 놓아도 핸들 위치 유지. 시작 화면에서 자동 복귀를 켤 수 있음) |
| X | 핸들 중앙으로 |
| B | 안전벨트 착용/해제 |
| N | 주차 브레이크 체결/해제 |
| Space | 브레이크 |
| R / F | 포크 상승·하강 |
| T / G | 마스트 전경·후경 |
| Shift (누른 채) | 미세 조작 (저속·저속 리프트) |
| C | 시점 전환: 운전석 → 3인칭 → 위에서 보기 |
| 마우스 드래그 | 둘러보기 (더블클릭하면 초기화) |
| Q (누른 채) | 뒤돌아보기 |
| M | 소리 켜기/끄기 |
| H | 도움말 숨기기/보이기 |
| P / Esc | 일시정지 |

한글 입력 상태에서도 키가 동작합니다. 휴대폰이나 태블릿에서는 화면 오른쪽 아래 터치 버튼으로 조작합니다(PC에서는 숨겨짐).

## 구현 내용
- **운전석**: 오버헤드 가드, 좌석, 안전벨트, 스피너 노브가 달린 조향 핸들, 전후진(FNR) 레버, 리프트·틸트 유압 레버, 인칭·브레이크·가속 페달, 주차 브레이크, 미러, 경광등이 있습니다. 레버와 페달, 핸들은 조작에 맞춰 움직입니다.
- **계기판**: 운전석 3D 계기판이 실시간으로 바뀝니다. 속도계, 기어(F/N/R), 포크 높이, 마스트 각도, 남은 시간, 아워미터, 연료·냉각수 게이지, 경고등(벨트, 주차, 오일, 충전, 포크 높이, 미세, 후진)을 표시합니다.
- **차량 거동**: 앞(구동)축을 기준으로 뒷바퀴가 조향되는 기구학입니다. 회전할 때 차체 뒤쪽이 바깥으로 돕니다.
- **팔레트 판정**: 포크 구멍 높이·좌우 위치, 삽입 깊이, 드럼 위 하역 위치 편차, 팔레트 틀어짐을 판정합니다.
- **실격·감점**: 아래 표 기준으로 판정하고, 결과 화면에 시간순 기록을 보여줍니다.
- **시험 모드 / 연습 모드**: 시험 모드는 실격 즉시 종료되고, 연습 모드는 실격을 기록만 하고 계속 진행합니다.
- **보조 기능**: 정렬 보조 가이드(좌우 편차, 구멍 높이, 삽입 깊이, 드럼 정렬), 미니맵, 단계별 안내 문구가 있습니다.
- **소리**: 엔진음, 유압음, 후진 경고음이 납니다.
- **카메라**: 운전석 시점에서 후진할 때 자동으로 뒤를 돌아봅니다(옵션). 3인칭 시점은 적재·하역 구역에서 포크가 잘 보이는 측면 시점으로 바뀌고, 후진할 때는 앞쪽에서 진행 방향을 비춥니다.
- **팔레트 위치**: A·B 드럼 위 팔레트는 앞면이 적재선 5cm 안쪽에 있습니다. 캐리지가 닿을 때까지 넣으면 끝까지 삽입되고, 허용 범위는 약 20cm입니다.

## 판정 기준 (근사치)
| 구분 | 항목 |
|---|---|
| 실격 | 4분 초과(연습 모드는 기록 후 계속) · 주행 중 포크 50cm 초과 · 포크가 지면에 닿은 채 주행 · 팔레트 지면 접촉 · 바퀴의 코스 라인 접촉·이탈 · 차체·포크·팔레트의 드럼 접촉 · 포크 20cm 이상 덜 삽입 · 하역 위치 20cm 초과 이탈 |
| 감점 (-5) | 안전띠 미착용 · 출발 시 포크 높이 미준수 · 주행 중 포크 20~30cm 미유지(1.5초 이상, 최대 3회) · 운반 중 마스트 후경 미실시 · 포크로 팔레트 충돌 · 하역 편차 10~20cm · 팔레트 10° 이상 틀어짐 |

적재·하역 구역(A 드럼 앞, B 하역 직선 구간)에서는 포크 높이 주행 규칙을 적용하지 않습니다.

모든 수치는 `index.html` 상단의 `RULES` 객체와 코스 정의(`YARD`, `LANE`, `path`)에서 조정할 수 있습니다.

## 참고한 시험 절차
공개된 학원 안내문의 절차를 따랐습니다. 출발 위치에서 출발해 화물 적재선의 드럼통 위 팔레트를 적재하고 전진 코스로 운전합니다. 적하차 위치에 내린 뒤 후진선까지 후진해 포크를 지면에 완전히 내렸다가, 다시 전진해 적재합니다. 그다음 후진 코스로 출발선까지 와서 전진해 드럼통 위에 내려놓고, 후진해 처음 장비 위치에 정지합니다.

## 공식 기준과 한계
이 시뮬레이터는 교육용입니다. 코스 형태·치수와 채점 항목은 공개된 수험 정보 요약을 바탕으로 근사한 것입니다. Q-Net 공개문제 원문(도면, 요구사항, 실격 기준)과 다를 수 있고, 공식 점수를 산출하지 않습니다. 실제 시험 준비는 반드시 Q-Net 최신 공개문제로 확인하세요.

## 개발 메모
- 테스트를 위해 `window.__sim`으로 내부 상태(`S` 차량, `P` 팔레트, `G` 진행, `keys` 입력)를 노출합니다.
- 자동운전 스크립트로 전체 코스 완주를 반복 확인했습니다. 감점 없이 약 1분 40초에 합격했고, 저장소에는 포함하지 않았습니다.
- 별도 검토 에이전트의 점검 결과를 반영했습니다. 반영 항목은 한글 입력 대응, 출발 전 절차, 핸들 유지, 하역 판정, 실격 중복 기록, 카메라, 화면 배치입니다.
