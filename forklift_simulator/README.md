# 지게차 운전기능사 실기 시뮬레이터 (Prototype v0.2)

## 실행
1. `index.html`을 Chrome 또는 Edge에서 엽니다.
2. 인터넷 연결이 필요합니다. Three.js는 jsDelivr CDN에서 불러옵니다.
3. 시작 화면에서 좌석 안전띠 착용을 체크한 후 시작합니다.

## 조작
- W/S: 전진/후진
- A/D: 조향 (간이 후륜 조향 동작)
- Space: 브레이크
- R/F: 포크 올림/내림
- T/G: 마스트 전방/후방 기울임
- C: 1인칭/3인칭 전환
- P: 일시정지

## 이번 버전 반영
- 시작 전 좌석 안전띠 확인
- 약 4분의 실기 연습 카운트다운 (Q-Net 종목 상세정보의 작업형 시간 표기 참고)
- 기존 3D 지게차, 운전석 UI, 조향, 포크 조작 유지

## 공식 기준과 한계
Q-Net 공개문제(2025-12-22 등록)는 시험방법 변경 없이 요구사항 및 유의사항 문구 정비를 공지했습니다. 출제기준은 2025-01-01~2027-12-31 적용본입니다.
이 프로토타입은 교육용입니다. 현재 공개문제 PDF의 도면·세부 요구사항·세부 실격 기준을 전부 정밀 반영하거나 공식 점수를 산출하지 않습니다. 코스 치수와 채점 규칙은 공개문제 원문 도면/문구를 직접 대조한 후 별도 구현해야 합니다.
