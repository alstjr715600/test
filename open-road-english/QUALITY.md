# Open Road English — 품질 체크리스트

실제로 써보면서 이 항목들로 판단한다. `[x]` 반영됨, `[ ]` 아직, `[?]` 직접 써봐야 판단 가능.

## 1. 듣기 (음성 입력)
- [x] 길게 말해도 끊지 않음 (최대 60분, 직접 정한 침묵 시간에만 전송)
- [x] 전송·내 차례 알림음 (화면 없이 흐름 파악)
- [?] 자동 전송 타이밍: 생각하며 멈출 때 너무 일찍 보내지 않는지 → 4초/6초 중 맞는 값 찾기
- [?] 인식 정확도: 발음이 약한 단어가 엉뚱하게 받아써지는지 (교정에서 STT 오류를 문법 오류로 오인하면 안 됨)
- [?] 핸즈프리: AI 목소리를 내 말로 받아쓰는지 (차량 블루투스/이어폰으로 해결되는지)
- [ ] 한국어+영어 섞어 말할 때 처리 (지금은 마이크 언어 버튼으로 전환)

## 2. 대화 상대 (AI 답변)
- [x] 매 턴 질문 하나, 짧은 답, 내가 길게 말하게 유도
- [x] 같은 반응("Wow", "That's great") 반복 금지, 같은 질문 반복 금지
- [x] 긴 대화 기억: 최근 20턴은 그대로, 그 이전은 요약해서 전달 (비용 증가 억제)
- [?] 레벨별 난이도가 실제로 다르게 느껴지는지
- [?] 상황(카페·면접 등) 역할을 끝까지 유지하는지
- [ ] 대화 상대 성격·말투 고르기

## 3. 교정 품질
- [x] 교정 종류 표시: 문법 / 단어 선택 / 더 자연스럽게
- [x] STT 때문에 생기는 것(구두점, 관사 누락, 동음이의어)은 교정하지 않음
- [x] 바꾼 게 없는 "가짜 교정" 자동 제거
- [x] 끝난 뒤 복습은 더 똑똑한 모델(default)로 다시 분석
- [?] 틀린 걸 놓치거나, 맞는 걸 틀렸다고 하는 비율
- [ ] 정밀 교정 옵션 (턴마다 더 좋은 모델로 한 번 더 검사, 사용량 약 2배)

## 4. 말하기 (AI 음성)
- [x] 탭 대화 = Claude 음성 (고품질), 핸즈프리 = 기기 음성 중 최상 자동 선택 + 직접 선택
- [x] 답이 다 써지기 전에 읽기 시작 (응답 대기 시간 단축)
- [?] 속도 0.95 기본값이 적당한지
- [ ] 핸즈프리에서도 Claude 음성 (플랫폼 제약: 마이크가 켜져 있으면 Claude 음성 불가)

## 5. 학습 효과
- [x] 턴별 교정 카드, 표현 칩, 듣고 따라 말하기
- [x] 피드백 시점 선택 (바로 / 끝나고 한 번에), 바로 피드백 방식 (화면만 / 자연스럽게 / 확실하게 짚기)
- [x] 복습 노트 저장 (계정별 비공개)
- [ ] 따라 말하기 채점: 고친 문장을 말하면 맞게 했는지 확인
- [ ] 자주 틀리는 패턴을 다음 대화에서 일부러 다시 연습시키기
- [ ] 세션별 성장 그래프 (최장 턴, 분당 단어 수, 교정 수 추이)
